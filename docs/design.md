# 畫面設計結果

> 這份文件記錄 /design 做出來的最終畫面設計，供下一步做前端時對照。
> 行為與資料格式以 `docs/architecture.md` 為準；這份文件只負責「長什麼樣子」。
> 設計稿原件（Claude 的設計畫布，只有建立者能開）：https://claude.ai/artifact/T7ErHEMKNtGYHWvjDrgVCY

## 1. 設計方向

- **風格**：莫蘭迪色系、現代簡約。低飽和、偏灰的暖色調，留白多，沒有陰影與漸層（只有「有 N 則新訊息」按鈕有一道很淡的陰影）。
- **主色**：灰藍。用在頂部列、按鈕、自己的訊息氣泡、選中狀態。
- **背景**：暖灰米色，卡片與輸入區是更淺的灰米白。
- **字體**：Noto Sans TC（Google Fonts，字重 400、500、700）。
- **圖示**：全部是單色線條圖示（描邊 1.75，圓頭圓角），24×24 座標；不使用 emoji。
- **手機優先**：手機畫板 390×844，電腦畫板 1280×800。所有可點的東西至少 44×44px。

## 4. 各畫面做法

### 4.1 進入畫面

手機：整頁置中，由上到下：圖示 → 標題 → 簡介 → 表單。表單依序是：
1. **你的頭像**（標題 + 預覽 + 上傳按鈕 + 內建圖案列 + 底色列）
2. **你的代號**（標籤 + 輸入框 + 說明與字數）
3. 錯誤提示區（沒有錯誤時保留空間，避免畫面跳動）
4. 進入按鈕

電腦：左欄是灰藍底，放圖示、標題、簡介、三行說明（所有人都在同一個聊天室／電腦、手機都能用／最後一個人離開後，訊息就清空）；右欄是置中的卡片，標題「進入聊天室前」，內容同手機表單。

要點：
- 內建圖案列和底色列是 `role="radiogroup"`，每個鈕 `role="radio"` 並有 `aria-checked`；選中的內建圖案有 2px 主色外框，選中的底色圓點外面多一圈間隔加主色環。
- 已上傳圖片時：預覽變成上傳的圖片，內建圖案列與底色列暫時停用，按鈕變成「更換圖片」「移除，改用內建圖案」。
- 輸入框說明固定顯示「1 到 12 個字，中英文、數字都可以」，右邊是目前字數「n / 12」。
- 進入按鈕在代號格式不合時停用；按下後顯示「進入中…」並暫時停用。

### 4.2 聊天畫面

**頂部列**（灰藍底、米白字）：左邊標題「匿名聊天室」，下面一行「● N 人在線」。
- 手機：右邊兩個圖示鈕，「成員名單」與「離開」（離開圖示用淡紅）。
- 電腦：右邊只有一個帶圖示的「離開」文字按鈕；名單固定在右側，不需要名單鈕。

**訊息區**：訊息由下往上疊，內容靠底部對齊。
- 別人的訊息靠左：先一行「小頭像 + 代號」，下面是氣泡，氣泡旁（右下）是時間。
- 自己的訊息靠右：沒有代號與頭像，灰藍氣泡、米白字，時間在氣泡左下。
- 系統提示（某某 進來了／離開了）：置中的小膠囊，12px，`--bg-raised` 底。
- 圖片訊息：灰色佔位方塊（接後端後換成縮圖），可點開大圖。
- 檔案訊息：卡片裡有檔案圖示、檔名（過長以刪節號截斷）、大小、「下載」按鈕，卡片下方一行警示「下載前請確認來源」。
- 已編輯：訊息正下方一個小字按鈕「已編輯」（灰、底線），有 `aria-expanded`；展開後下面出現舊版本清單（見 4.5）。
- 已收回：虛線外框、斜體灰字「這則訊息已收回」，時間與位置保留。
- 「有 N 則新訊息 ↓」：浮在輸入區上方正中間的膠囊按鈕，灰藍底。只在使用者往上看舊訊息時出現。
- 電腦版滑鼠移到自己的訊息上，氣泡旁出現小工具列「編輯」「收回」。手機版改用長按，出現同樣的選項（選單樣式見 4.5，設計稿未另畫長按的手勢）。

**輸入區**（灰米白底，上方一條細線）：
- 手機：附件鈕（左）→ 膠囊形輸入框 → 圓形送出鈕。
- 電腦：附件鈕 → 輸入框（提示「輸入訊息，Enter 送出，Shift+Enter 換行」）→ 帶字的「送出」按鈕。

### 4.3 名單

手機獨立頁：頂部列有返回鈕、標題「成員」、右邊「12 / 50」。每列：頭像 → 代號（自己多一個「你」徽章）與狀態 → 右邊「隱藏」鈕。被隱藏的人整列變淡（不透明度 0.75），頭像換成「眼睛劃線」圖示，旁邊多「已隱藏」徽章，按鈕變「取消隱藏」。

電腦：右側固定欄，標題列「成員」加「12 / 50」，列的內容相同，尺寸稍小。

### 4.4 錯誤與狀態提示

提示的形狀統一：圓角矩形、左邊一個圓形驚嘆號圖示、一行文字，14px。
- 錯誤：`--danger-bg` 底、`--danger` 字。
- 警示（人數已滿、斷線）：`--warn-bg` 底、`--warn` 字。
- 一般資訊（你已離開聊天室、圖片處理中）：`--bg-raised` 底、`--ink-2` 字。

設計稿「各種狀態」畫板裡涵蓋：代號被用、聊天室已滿、代號格式不合、已離開、進入按鈕停用與載入中、斷線橫幅加停用的輸入區、文字超過 1000 字（外框變紅、顯示「1032 / 1000，請縮短後再送出」）、附件預覽與上傳進度與取消、檔案過大、送出失敗重試、空狀態、分頁標題未讀數、頭像的上傳中與失敗。

### 4.5 選單、編輯與對話框

- **訊息操作選單**：小面板（寬 140px），選項高 40px。自己的文字訊息有「編輯」「收回」；自己的檔案只有「收回」。「收回」用 `--danger` 字。
- **編輯模式**：原訊息的氣泡變成灰藍底的框，裡面是輸入框（淺底、深字）加「取消」（描邊）與「儲存」（米白底、灰藍字）。
- **已編輯展開**：不是視窗。點「已編輯」後，就在該訊息正下方展開一個小清單（寬 300px，圓角 12px，底色用 `--bg-raised`，才能在頁面背景上看得出來；設計稿的示範卡片為了對比用了 `--bg-page`），列出「修改前 · 時間」與「原始送出 · 時間」及各自內容；再點一次收合。箭頭圖示向下（收合）／向上（展開）。
- **離開確認**：置中對話框，「確定要離開嗎？」＋說明＋「取消」「離開」，「離開」是紅色底。
- **圖片大圖**：遮罩上置中放大圖，右上角圓形關閉鈕。

### 4.6 @ 提及（設計稿之後新增，未畫進設計稿）

這一段是設計稿完成之後加的功能，設計畫布裡沒有畫；以下是實作時採用的樣式，之後如果更新設計稿，以設計稿為準。

- **成員選單**：輸入框上方浮出的小面板（圓角 12px、`--bg-surface` 底、`--line-strong` 外框、淡陰影），最高約 248px 可捲動；每列高 44px，左頭像（26px）、中間代號、右邊「線上／離線中」；選中的列用 `--bg-raised` 底。手機與電腦都是貼著輸入列上緣。
- **訊息裡的 @代號 標籤**：圓角 6px、左右內距 4px、字重 500；一般氣泡裡是半透明灰藍底，自己的灰藍氣泡裡是半透明米白底；被提到的是你時，標籤用 `--mention-bg`／`--mention-ink`。
- **「提到你」**：別人的訊息，代號旁多一個膠囊小標（`--mention-bg` 底、`--mention-ink` 字、11px）；氣泡外面多一圈 2px 的 `--mention`。
- **分頁標題**：有人 @ 你時，未讀數前面多「@」，例如「(@2) 匿名聊天室」。

### 4.7 回覆（設計稿之後新增，未畫進設計稿）

- **觸發**：電腦滑過訊息出現的小工具列、手機長按出現的選單，都多了「回覆」（別人的訊息只有「回覆」，自己的訊息還有「編輯」「收回」）。
- **回覆列**（輸入區上方）：圓角 12px、`--bg-raised` 底；左邊回覆圖示、中間兩行（「回覆 某某」12px／內容 13px 單行刪節號）、右邊取消鈕（44px）。
- **訊息上方的引用**：和訊息同一側對齊的小塊，圓角 12px、`--bg-surface` 底、`--line` 外框、12px 灰字；內容是回覆圖示、代號（字重 500）、前兩行內容；圖片與檔案多一個對應圖示與檔名。可點時 hover 變 `--bg-raised`；原訊息已收回時整塊斜體、不可點。
- **「回覆你」**：和「提到你」同一款小標與外框（`--mention` 系列），可同時出現。
- **跳回原訊息**：捲到畫面中間，並用 1.6 秒的淡淡灰藍底色閃一下（尊重「減少動態效果」設定）。

## 5. 設計稿沒有畫、做前端時要自己決定的事

- 手機版訊息「長按」出選單的手勢與動畫。
- 各種過場動畫（進入、離開、展開、新訊息出現）：建議都很短（150–200ms）、淡入淡出即可，並尊重使用者的「減少動態效果」設定。
- 鍵盤出現時，手機輸入區要貼著鍵盤上緣、訊息區跟著縮小。
- 圖片、檔案在載入中的樣子（現在是靜態灰色方塊）。
- 很長的代號或訊息如何換行（原則：訊息自動換行、代號與檔名以刪節號截斷）。
- 深色模式：這一版沒做。
- 連結：訊息中的網址是純文字、不能點（已在架構文件決定）。
